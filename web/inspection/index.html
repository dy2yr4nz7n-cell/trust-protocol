Methodik und Grenzen

SHA-256
Kryptografischer Fingerabdruck der hochgeladenen Bytes. Gleiche Bytes ergeben denselben Hash.
C2PA
Validierung vorhandener Content Credentials über das offizielle c2patool. Das Ergebnis wird nicht aus dem Dateinamen abgeleitet.
EXIF
Vorhandene ausgewählte Metadaten werden angezeigt. Metadaten können fehlen, entfernt oder gefälscht sein.
Kein KI-Detektor
Diese Version führt keine KI-basierte Deepfake- oder Pixel-Manipulationserkennung aus.
Beweiswert
Der Audit-Bericht dokumentiert die geprüften Bytes und das Ergebnis zum Prüfzeitpunkt. Er ersetzt keine sachverständige Untersuchung oder beweissichere Beweismittelkette.
Ein valides C2PA-Manifest bestätigt eine kryptografische Herkunfts-/Integritätsaussage im Rahmen der signierten Daten. Es garantiert weder die Wahrheit des Inhalts noch, dass eine Aufnahme die Realität korrekt wiedergibt.
